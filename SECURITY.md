# Security Policy

## Supported versions

Security fixes are made on the latest 1.x release line.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately
to the CBS-HPC maintainers through the contact route listed in the repository
organisation profile. Include the affected version, a minimal reproduction,
impact, and any suggested mitigation.

Maintainers will acknowledge the report, assess impact, coordinate a fix, and
publish a release note after remediation.
